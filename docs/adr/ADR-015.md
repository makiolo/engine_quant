# ADR-015: QuantContext client-owned e inmutable

- **Estado:** aceptado como baseline de Fase 0; sujeto a evidencia de benchmarks.
- **Contexto:** La API nueva debe separar transporte, planificación, dominio financiero y providers legacy.
- **Decisión:** El cliente conserva snapshots tipados, versionados y hasheados; el servidor reconstruye desde el request.
- **Trade-off:** Se repite o comprime contexto y el cliente conserva la responsabilidad del estado lógico.
- **Revisión:** Cambiar este ADR requiere registrar el caso de benchmark, fixture y fecha que justifican el cambio.
