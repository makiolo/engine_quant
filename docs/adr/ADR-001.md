# ADR-001: Axum/Tower sobre Actix para v1

- **Estado:** aceptado como baseline de Fase 0; sujeto a evidencia de benchmarks.
- **Contexto:** La API nueva debe separar transporte, planificación, dominio financiero y providers legacy.
- **Decisión:** Se adopta Axum y middleware Tower como stack HTTP inicial.
- **Trade-off:** Se prioriza coherencia con el resto del stack sobre diferencias marginales de router; comparar Actix solo si el benchmark HTTP real muestra una diferencia relevante.
- **Revisión:** Cambiar este ADR requiere registrar el caso de benchmark, fixture y fecha que justifican el cambio.
