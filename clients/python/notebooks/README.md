# Notebooks

`demo_registry.ipynb` es la demo/tutorial del registry (PLAN.md §5.4/§7.6) desde Python.
Requiere haber compilado el proyecto con CMake antes (ver `PLAN.md` en la raíz).

Para lanzarlo:

```bash
pip install jupyterlab matplotlib
cd clients/python/notebooks
jupyter lab demo_registry.ipynb
```
